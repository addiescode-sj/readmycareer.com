# 제품 전략 캔버스 — readmycareer.com

---

## 1. 비전

> **누구나 자신의 현재 커리어와 목표 사이의 격차를 파악하고 좁혀나갈 수 있도록 — 기존의 어떤 커리어 코치도 이 가격과 속도로 제공할 수 없었던 솔직한 AI 인사이트로.**

- 우리는 시간당 수십만 원짜리 전문 코치를 고용할 수 있는 사람만이 아니라, 모든 사람이 자신의 커리어 궤적을 명확하게 파악할 자격이 있다고 믿습니다.
- 우리는 야심 있는 직장인들을 위한 기본 커리어 인텔리전스 플랫폼이 되는 것을 목표로 합니다.
- 우리는 칭찬보다 솔직함을 추구합니다. 우리 제품은 듣고 싶은 말이 아니라, 실제로 부족한 것을 알려줍니다.

| **원하는 결과** | 막연한 조언이 아닌, 구체적이고 우선순위가 정해진 실행 계획 |

테크 직군으로 전환을 원하는 비테크 직장인 (예: 금융 → 데이터, 운영 → PM). 기존 경험의 이전 가능성에 대한 불안감이 높습니다. 불확실성을 줄이기 위해 비용을 지불할 의향이 있습니다.

## 3. 상대적 비용 포지션

**포지션: 저비용이 아닌 프리미엄 가치.**

무료 도구(ChatGPT 프롬프트 활용, Jobscan 무료 플랜)와 가격으로 경쟁하지 않습니다. 우리의 비용 구조는 다음을 반영합니다.
- 분석당 LLM 추론 비용 (Gemini 2.5 Flash — 이미 검증된 비용 효율적 모델)
- 에이전트 오케스트레이션 (갭 분석 + 플래너 + 채팅 Q&A 파이프라인)
- 대규모 인간 코칭 팀 불필요 = 인간 코치 대비 구조적 비용 우위

**단위 경제 목표:** 세션당 AI 추론 비용 $0.10 미만으로 유지하여, 프리미엄 또는 월 $15~25 구독 모델에서 건전한 마진 확보.

## 6. 핵심 지표

**북극성 지표 (North Star Metric):**
> **갭 분석을 완료하고 커리어 플랜의 최소 1주차를 실행한 사용자 수**

분석 완료(활성화)와 플랜 실행(리텐션)을 모두 포착하며, 장기적인 가치 제공을 직접적으로 예측합니다.

**Q1 OMTM (현재 가장 중요한 단일 지표, 런칭 전 → 첫 100명):**
> **활성화율** — 첫 세션 내에 갭 분석을 완료한 가입자 비율

*이유:* 런칭 전 단계에서는 핵심 루프(이력서 입력 → 실행 가능한 플랜 출력)가 작동한다는 것을 증명하는 것이 전부입니다. 활성화율이 40% 미만이면 제품이 제 역할을 못하는 것입니다.

## 7. 성장 전략

**방식: 제품 주도 성장 (PLG)**

| 단계 | 전략 |
|---|---|
| **0 → 100명** | 직접 아웃리치 — 창업자가 링크드인/X에 갭 분석 사례를 공유. 관련 커뮤니티(Blind, Levels.fyi, 테크 트위터)에서 베타 사용자 초대. |
| **100 → 1K명** | 공유 가능한 결과물 — 사용자가 게시할 수 있는 공개 "커리어 갭 리포트" 카드 생성. 제품 자체에 바이럴리티 내재화. |
| **1K → 10K명** | SEO + 비교 콘텐츠("readmycareer vs Jobscan", "AI로 이력서 분석하는 법") + 추천 프로그램. |
| **10K명+** | B2B 채널 — 부트캠프, 코딩 스쿨, 대학 취업지원센터가 학생들을 위해 도구 도입. |

**단위 경제 목표:** CAC < LTV의 1/3. 월 $20 구독 기준, LTV(평균 6개월) = $120 → CAC 상한 = $40.

**프리미엄 구조:**
- 무료: 월 1회 갭 분석, 플래너 미포함
- 프로 (월 $19): 무제한 분석 + 전체 주별 플래너 + 채팅 Q&A

## 9. 불가능 / 불필요 (방어력)

| 해자 | 구축 방법 |
|---|---|
| **출력 품질 플라이휠** | 각 분석 + 사용자 피드백이 평가 벤치마크를 학습시킵니다. 시간이 지날수록 구조화된 평가를 운영하지 않는 경쟁자보다 프롬프트와 점수가 빠르게 개선됩니다. |
| **커리어 궤적 맥락** | 이력서 스냅샷이 아닌 전체 커리어 흐름을 분석합니다. (동의 하에) 종단 데이터를 축적하면 시간이 지날수록 더 풍부한 모델이 됩니다. |
| **전환 비용** | 사용자가 갭 리포트 + 8주 플랜을 보유하면, 이탈 시 처음부터 다시 시작해야 합니다. 플랜 연속성과 진행 상황 추적이 잠금 효과를 심화시킵니다. |
| **한국 시장 선점** | 한영 이중 언어 지원 이미 구축 완료. 한국 테크 채용 시장은 영어 우선 도구들에게 여전히 미개척 시장입니다. 조기 브랜드 구축은 지속 가능한 우위입니다. |

**경쟁자들이 쉽게 따라올 수 없는 이유:**
- Jobscan은 키워드를 최적화합니다 — 근본적으로 다르고 훨씬 얕은 문제 정의입니다.
- 링크드인 프리미엄은 데이터는 있지만 분석 제품이 없습니다; 그들의 인센티브는 사용자를 플랫폼에 머물게 하는 것이지, 더 좋은 직장을 찾도록 돕는 것이 아닙니다.
- ChatGPT는 사용자가 PM 역할을 해야 합니다 — 우리 제품은 그 생각을 대신해줍니다.

## 부록: 이력서 최적화 — 커리어 플랜의 실물 아웃컴으로의 전환

이력서 최적화 기능은 커리어 플랜을 "계획 도구"에서 "취업 지원 도구"로 변환시킵니다. 이는 제품의 가치 제안을 실질적으로 강화합니다:

- **완료 루프:** 이력서 생성 기능을 잠금 해제하기 위해 모든 체크리스트를 완료해야 하므로, 사용자 리텐션과 플랜 완료율이 향상됩니다. 한 번 생성되면 "✓ 생성 완료" 버튼 상태가 페이지 새로고침 이후에도 Supabase 기반으로 영구 유지되어, 사용자의 성취감과 진행 인식을 강화합니다.
- **즉시 활용 가능한 결과물:** 갭 분석이나 주간 플랜과 달리, 최적화된 이력서는 취업 지원에 즉시 사용할 수 있습니다 — 풀스크린 모달로 조회, 마크다운으로 복사, `.md` 파일 다운로드, 또는 클린 PDF 내보내기(브라우저 인쇄 헤더/푸터 제거, 외부 링크 `https://` 정규화) 지원.
- **차별화된 포지셔닝:** 경쟁사는 이력서 빌더 또는 커리어 플래닝을 별도로 제공합니다. readmycareer.com은 갭 식별 → 성장 실행 → 이력서 합성을 하나의 워크플로우로 연결하는 유일한 도구이며, Gemini 멀티모달 LLM이 이를 구동합니다.
- **PLG 바이럴 벡터:** 생성된 이력서에는 플랫폼의 출력물(JD 매칭 키워드, 구조화된 템플릿)이 반영됩니다. 결과물의 품질을 본 채용 담당자들이 입소문을 유발합니다.
- **데이터 플라이휠:** 각 최적화 호출(로케일, 적용 키워드, 생성된 섹션)은 `resume-generator` MCP 스킬의 품질 향상을 위한 평가 파이프라인에 신호를 추가합니다.
